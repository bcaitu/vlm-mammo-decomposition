# Статья 4: предрегистрация диагностики «восприятие или вербализация» (s4diag)

Версия 1.0, 2026-10-05, до извлечения признаков и генерации на выборке разработки. Хэши записываются на сервере в `prereg/s4diag_hashes.txt`.

## 0. Статус и прозрачность

Это разведочная диагностика, не подтверждающее исследование. Результаты исследований 1 и 2 известны: сквозная VLM называет очаги редко (чувствительность по массе 0,20–0,29, по кальцинатам 0,01–0,06, по асимметрии 0,01–0,05 при специфичности около 0,98). Диагностика проверяет, почему. Адаптеры (три сида) те же, обучение не повторяется. Выборка разработки взята из валидационной части EMBED, не из свежих строк исследования 2. Из 1000 валидационных исследований, по которым считались потери при обучении, часть может попасть в выборку; отбора по ним не было (одна эпоха, один рецепт). Если исход укажет на разрыв вербализации, подтверждение будет проведено отдельно на нетронутых строках EMBED Hologic и GE-holdout с новой предрегистрацией.

## 1. Вопрос

Для находок mass, calc и asymmetry: информация о находке есть во внутренних представлениях VLM и в её собственных вероятностях, но не доходит до жадно сгенерированного текста («разрыв вербализации»), или её нет и в представлениях («разрыв восприятия»).

## 2. Данные

Валидационные исследования EMBED из дампа стадии 1 (9 020 исследований; 1 362 с очагом, 6 774 без очага с размеченным отсутствием массы или кальцинатов). Выборка зерном 20261006: 1000 исследований с очагом и 1000 без очага, 1091 пациент. Части по хэшу пациента: train 50% (993 исследования), select 20% (387), test 30% (620).

| Находка | train: есть / нет | select | test |
|---|---|---|---|
| mass | 126 / 499 | 50 / 209 | 104 / 299 |
| calc | 153 / 502 | 52 / 210 | 96 / 300 |
| asymmetry | 239 / 502 | 84 / 208 | 141 / 300 |

## 3. Величины

Для каждого сида (0, 1, 2) и находки, на части test:
1. Жадная генерация: чувствительность и специфичность слота (слот «present» по экстрактору).
2. Оценка модели: −log P(« No» в начале предложения о находке) при принудительной подаче канонического отрицательного отчёта, где первое предложение (плотность) написано самой моделью, а предложения о других находках канонические отрицательные. AUC этой оценки.
3. Линейные пробы: логистическая регрессия (L2, сбалансированные веса, стандартизация) на скрытых состояниях последнего токена подсказки или среднего по токенам изображения, слои 0, 8, 16, 20, 24, 28, 32, 36, C ∈ {0,001; 0,01; 0,1}. Конфигурация выбирается по AUC на части select, обучение на train, отчёт на test.
4. Эталон специалиста: AUC выхода «present» головы стадии 1 (среднее шести прогонов cb_embed).
5. Контроль: те же пробы на базовой Qwen3-VL-8B без адаптера (описательно).
AUC усредняется по сидам. 95% ДИ: бутстреп по пациентам на части test (1000 реплик).

## 4. Правила решения (фиксированы до запуска)

Для находки: «разрыв вербализации» V, если AUC пробы ≥ AUC головы стадии 1 − 0,05 и чувствительность жадной генерации ≤ 0,10; «разрыв восприятия» P, если AUC пробы ≤ 0,60.
Исход: «разрыв вербализации», если V выполнено не менее чем для двух из трёх находок и P менее чем для двух; «разрыв восприятия», если P не менее чем для двух и V менее чем для двух; иначе «промежуточный».
Описательно, без правила: достижима ли разница через оценку модели (AUC оценки ≥ AUC головы − 0,05, «восстановимо порогом»); чувствительность при специфичности 0,90 для оценки модели, пробы и головы стадии 1; значения базовой модели.

## 5. Что будет сообщено

Все три находки, все сиды, выбранные конфигурации проб, обе стороны правил решения, независимо от исхода.

## 6. Ограничения

Положительных примеров мало (на обучение пробы 126–239, на выбор 50–84, на отчёт 96–141), поэтому ДИ широкие и выбор конфигурации шумный. Выборка стратифицирована по меткам и взята из одного набора (EMBED, валидация). Каноническая оценка отличается от реального распределения генерации, когда предыдущие находки присутствуют. Пороги 0,05, 0,10 и 0,60 назначены заранее без калибровки. Проба показывает, что информация линейно считывается, а не что модель использует её причинно.

## 7. Порядок

Хэши скриптов, списка строк и весов; кэш изображений выборки; генерация жадным декодированием (3 сида) на выборке; извлечение признаков (3 сида и базовая модель); анализ запускается автоматически.
