# paper4_s8_code.zip: код s8 (статья 4)

Серверные скрипты выполнялись из `~/cbmammo` (окружение `~/envs/cbmammo`, `PYTHONPATH=$PWD:$PWD/analysis_embed`); локальные: `s8_reading.py`, `s8_figure.py`, `build_s8_report.py`.

Порядок:
1. `s8_prereg_ru.md` — предрегистрация; `s8_freeze1.sh` — запись хэшей фазы 1 до основных прогонов; `s8_smoke.txt` — результат пробного запуска (скорость и память).
2. `s8_make_tasks.py` — список из 19 задач (пилот скорости обучения башни, VC, V2x, извлечение признаков, пробы); `s8_run_queue.sh` и `s8_phase2_driver.sh` — запуск очереди; `s8_train.py` — обучение (рецепт `lc_train.py` плюс `--tower_lora`, `--lr_vis`).
3. `s8_pick_lrvis.py` — выбор скорости обучения башни по правилу предрегистрации; `s8_freeze2.sh` — хэши фазы 2 до запуска VC.
4. `s8_final.sh` — автоматический конвейер: `s8_precheck.py` (полнота рукавов и тестовой выборки), проверка хэшей, один запуск `s8_analysis.py`, `s8_collect_meta.py`.
5. `s8_analysis.py` — исправленный (отклонение 1, `s8_deviations.md`); `s8_analysis.py.orig_frozen` — замороженный до правки.
6. `s8_posthoc.py` и `s8_posthoc2.py` — постхок-контрасты и разности «рукав − D» (не предрегистрированы; хэши записаны до запусков).
7. Локально: `s8_reading.py` (механическое чтение исходов), `s8_figure.py` (рисунки), `build_s8_report.py` (сборка отчёта из файлов; интерпретация вставляется из `s8_interpretation_ru.md`), `s8_syn_gen.py` (синтетическое дерево для проверки скриптов анализа и отчёта до запуска).

Зависимости данных: адаптеры, признаки и оценки s6lc (рукава V, VP, D, A_probe, A_tf, V_ctl) читаются из `runs_lc/`; данные EMBED, VinDr-Mammo, CBIS-DDSM в архив не входят. Контрольные суммы: `SHA256SUMS`.

Контрольные суммы пересчитаны 2026-10-09 после исправления той же формулировки в `build_s8_report.py` (генератор отчёта, не входит в замороженный набор `s8_hashes*.txt`); замороженные файлы не менялись, их хэши совпадают.
