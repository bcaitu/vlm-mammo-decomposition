# paper4_s8_tables.zip: выходы анализа s8 (статья 4)

Все файлы лежат в корне архива, кроме `posthoc_dup/` (дублирующие выходы постхок-запуска для проверки воспроизводимости). Данные уровня строки (идентификаторы EMBED, оценки по железам) остаются на сервере и в архив не входят.

Основной анализ (`s8_analysis.py`, один запуск 2026-10-09 17:26:45–17:27:08, бутстреп по пациентам теста, 2 000 повторов, seed 20261007):
- `s8_auc.csv` — AUC по рукавам и находкам (среднее по сидам, 95 % интервал по пациентам, SD между сидами);
- `s8_auc_by_run.csv` — AUC каждого прогона (рукав, находка, сид), число положительных и отрицательных;
- `s8_contrasts.csv` — контрасты S1–S5 и описательные, с вердиктами по правилам предрегистрации;
- `s8_meta.json`, `run_meta.json` — найденные рукава и сиды, метаданные обучений (шаги, секунды, число обучаемых параметров, потери);
- `s8_reading.md` — механическое чтение по таблице исходов предрегистрации (раздел 6), `s8_reading.py` в архиве кода;
- `analysis.log`, `final.log`, `precheck.log`, `queue.log`, `hashcheck_main.log`, `hashcheck_phase2.log`, `hashcheck_dev1.log` — журналы конвейера и проверок хэшей;
- `s8_hashes_phase2.txt`, `s8_hashes_dev1.txt`, `s8_hashes_ops.txt`, `s8_deviations.md`, `s8_phase2_ru.md`, `pilot_choice.json` — фаза 2, отклонение 1, хэши исполнительных скриптов, выбор скорости обучения башни.

Постхок (не предрегистрирован; `s8_posthoc.py`, хэш записан до запуска, `s8_hashes_posthoc.txt`):
- `s8_posthoc.csv` — контрасты P1–P6; `s8_posthoc_vctl_auc.csv` — AUC V_ctl; `posthoc.log`; `posthoc_dup/` — повтор основных таблиц AUC (побайтно равны основным).

Постхок 2 (не предрегистрирован; `s8_posthoc2.py`, хэш записан до запуска, `s8_hashes_posthoc2.txt`):
- `s8_posthoc2_gap_to_D.csv` — разности «рукав − D» для всех рукавов и находок; `posthoc2.log`; `posthoc2_dup/` — повтор основных таблиц AUC (побайтно равны основным).

Текст интерпретации: `s8_interpretation_ru.md` (раздел 4 отчёта).
Контрольные суммы SHA-256 всех файлов: `SHA256SUMS`.

Контрольные суммы пересчитаны 2026-10-09 после исправления формулировки про зазор («после каждого вмешательства по отдельности») в `s8_interpretation_ru.md`; файлы замороженного набора (`s8_hashes*.txt`) не менялись, их хэши совпадают.
